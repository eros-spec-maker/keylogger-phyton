# Uso Seguro e Responsável

Este projeto é **exclusivamente educacional**. Antes de executar o script,
leia e siga este guia.

## Ambiente recomendado

Execute este projeto **somente** em:

- Máquina virtual (VirtualBox, VMware, QEMU) descartável.
- Sistema que você possui e administra.
- Laboratório isolado, sem dados pessoais ou credenciais reais.

## Checklist antes de rodar

- [ ] Estou em uma VM ou máquina própria?
- [ ] O ambiente não contém dados sensíveis?
- [ ] Entendi o que o código faz (li `keylogger_educacional.py`)?
- [ ] Não vou usar isso em dispositivo de terceiros sem consentimento?

## O que fazer com o log

- Mantenha `keylog.txt` **somente localmente**.
- Não faça commit, upload ou compartilhamento do log.
- Apague ao final do experimento: `rm keylog.txt`.

## Sinais de uso antiético (evite)

- Executar sem confirmação do dono do dispositivo.
- Adicionar envio remoto, e-mail, auto-start ou stealth.
- Renomear o processo para parecer legítimo.
- Distribuir como "ferramenta pronta" para terceiros.

Se você precisa de alguma dessas funcionalidades, **pare**. O projeto deixou de
ser educacional e passou a ser potencialmente malicioso.
